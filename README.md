# SAM Frontend

A Christian content management platform built with Next.js, TypeScript, and MDX. The platform consists of a public-facing website for readers and a powerful admin dashboard for dynamic content management.

> SAM — Sharing the everlasting gospel through organized biblical content.

### Live Demo
- Website: `https://second-advent-ministries.vercel.app`
  

---

### Features

**Public Website**
- Clean, responsive reading experience
- Content organized by categories (Bible Study, Health, Family)
- MDX-powered articles with rich formatting
- SEO optimized
- Search and filtering

**Admin Dashboard**
- Secure authentication
- Create, edit, delete, and publish content dynamically
- Manage categories and hero metadata
- Media management (Cloudinary integration)
- No code deploys needed to update website content

### Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Content:** MDX
- **Styling:** Tailwind CSS
- **Media:** Cloudinary
- **Deployment:** Vercel
